Penyiapan pertama kali — ikuti berurutan

Lakukan sekali saja. Kamu tidak perlu mengubah workflow jadwal harian yang sudah berjalan.

  1. Buka n8n dari Control Center Desktop. Buka terminal menu AI Job Seeker - Control Center (D:), ketik 10, lalu tekan Enter. Browser n8n akan terbuka.
  2. Impor workflow baru. Di n8n, pilih menu import dari file dan pilih n8n_manual_discovery_score.json dari folder paket update yang sudah diekstrak. Nama workflow: AI Job Seeker - Manual Discovery & Score. Jangan mengganti workflow harian.
  3. Atur keamanan pada node Manual Trigger. Buka node itu dan pilih autentikasi Header Auth. Pada Credentials, buat credential baru dengan Header Name X-AIJobSeeker-Token. Untuk membuat token, buka jendela PowerShell baru (bukan menu Control Center), jalankan perintah di bawah, lalu salin hasilnya secara privat.
python -c "import secrets; print(secrets.token_urlsafe(32))"
  1. Masukkan API key proyek. Pada node Discover Jobs dan Score Jobs, ganti teks REPLACE_WITH_JOBSEEKER_API_TOKEN dengan nilai JOBSEEKER_API_TOKEN dari file {{ project_root }}\.env. Jangan kirim atau tampilkan token lewat chat/screenshot.
  2. Hubungkan dan aktifkan. Pastikan alurnya Manual Trigger → Discover Jobs → Score Jobs. Tidak boleh ada node Auto Apply/email. Klik Save lalu Publish/Activate workflow. Gunakan URL webhook produksi: http://127.0.0.1:5678/webhook/ai-job-seeker-manual.
  3. Simpan pengaturan di dashboard. Buka {{ project_root }}\.env menggunakan Notepad. Biarkan semua baris lama, lalu tambahkan dua baris di bawah. Ganti nilai kedua dengan token yang sama persis seperti Header Auth.
N8N_MANUAL_WEBHOOK_URL=http://127.0.0.1:5678/webhook/ai-job-seeker-manual
N8N_MANUAL_WEBHOOK_TOKEN=MASUKKAN_TOKEN_YANG_SAMA_DARI_LANGKAH_3
Terakhir: restart Dashboard lewat menu desktop. Kembali ke terminal AI Job Seeker - Control Center (D:), ketik 7, lalu tekan Enter untuk Restart Dashboard. Jangan mengetik perintah Python pada menu bernomor tersebut. Workflow harian tidak perlu diubah.

Setelah restart, buka dashboard lagi (pilihan 9 pada Control Center) dan klik Jalankan workflow sekarang. Untuk memastikan proses selesai, buka n8n lalu pilih Executions; pastikan node Discover Jobs dan Score Jobs berhasil.
